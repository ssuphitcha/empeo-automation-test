# Test Cases: empeo registration system (ordered by page flow)

URL: https://portal.uat.gofive.co.th/Register/empeo · Source: explored on UAT 2026-11-03/04
Format: Test ID `TC-REG-BUS-NNN` · Steps and Expected Results are 1:1 in count · Empty Precondition uses `-`
Test Type uses Positive/Negative and Priority uses High/Medium/Low (if the team uses other values, change them in one pass across the whole file)
API Base URL = `https://portal-uat-api.gofive.co.th`
This currently covers the **`บริษัทจดทะเบียนในไทย`** option (Thai-registered company); for the **`อื่นๆ`** option (Others) it starts at the company name field (BUS-099–114, after the button section); the remaining fields are the same as in Thai mode
Cases up to BUS-097 and BUS-099–114 never submit a valid registration. Cases BUS-098 and BUS-115–146 do submit real registrations on UAT with phone 0967690708, so every such run needs a new email (`empeo.qa.<timestamp>@gmail.com`, never example.com) and a new company (the tax ID `0105522023570` made OTP fail)

A Note starting with **Actual result** is what was observed on UAT but has no spec confirming it is correct.
